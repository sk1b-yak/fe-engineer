FE Engineer

A front-end engineer agent on the Cloudflare Agents SDK — built-in Biome linting + UI wiring audit.

checking agent…

Capabilities

  • generate_component — writes a React/TSX file, then runs a Biome lint-and-fix loop until the code is clean.
  • lint_fix — format + lint + self-correct any code you paste.
  • audit_ui — verifies every button does something: flags no-op handlers, handlers referencing undefined symbols, undefined components, and bare buttons. Optionally clicks every button on a live URL.

Connect (WebSocket)

The agent is a Durable Object routed by the SDK. Each session is its own instance:

wss://<this-host>/agents/fe-engineer/<session-id>

Use the React client hooks for a full chat UI:

import { useAgent } from "agents/react";
import { useAgentChat } from "@cloudflare/ai-chat/react";

const agent = useAgent({ agent: "FeEngineer", name: "playground" });
const { messages, input, handleInputChange, handleSubmit } = useAgentChat({ agent });
